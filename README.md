# Activity Planning Application

This application allows the management of a list of activities, including adding, deleting, modifying, and displaying activities. The app also provides search, filtering, and sorting functionalities based on various criteria.

### 🚀 Technologies Used
- **Programming Language**: C++ 
- **GUI Framework**: Qt for building the graphical user interface.
- **Activity Management**: Enables CRUD operations (Create, Read, Update, Delete) for managing activities.

### 🔍 Features Implemented
- **Add Activity**: Add new activities with details such as title, description, type, and duration.
- **Update Activity**: Modify existing activity details.
- **Delete Activity**: Remove activities from the list.
- **Display Activities**: View all activities.
- **Search Activity**: Find activities by title or description.
- **Filter Activities**: Filter activities based on description or type.
- **Sort Activities**: Sort activities by title, description, or type + duration.

### 💡 Key Insights
- The application provides a simple interface for managing activities, making it easier for users to plan and organize tasks.
- Search, filter, and sort functionalities make it easy to find and manage specific activities based on the user's needs.
